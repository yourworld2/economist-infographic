### Mood-specific notes / 各 mood 关键差异

#### newspaper-serious
- **EN** — Serif Milo TE title (not sans). Red appears ≤ 2 times (flag + protagonist series only). Cream background is forbidden (looks "old"). 595–640 px width for a "print column" feel.
- **中文** —— 标题用衬线 Milo TE（非 sans）。红色 ≤ 2 处（仅 flag + 主角 series）。禁止奶油背景（显旧）。595–640 px 宽，走"印刷专栏"质感。

#### classic-crimson *(default / 默认)*
- **EN** — The most recognisable "Economist" voice. Sans Econ Sans title. Red on protagonist series. The recommended default.
- **中文** —— 最具辨识度的"经济学人"声线。标题 sans（Econ Sans）。红色用在主角 series 上。默认推荐。

#### colorful-explainer
- **EN** — Data split into 4 phase series, each in a distinct palette hue (Chicago blue / Hong Kong aquamarine / New York gold / Singapore orange). **Red is flag-only**, never on a series. 800 px wide.
- **中文** —— 数据拆成 4 个阶段 series，每个用 palette 里的不同色（Chicago 蓝 / Hong Kong 青绿 / New York 金 / Singapore 橙）。**红色只给 flag**，绝不放在 series 上。800 px 宽。

#### monochrome-spare
- **EN** — Black ink protagonist, at most one Chicago-30 accent (used exactly once, e.g. the 2020 trough). **1 px red rule replaces both the 10×30 flag and the 2 px top border**. Serif title.
- **中文** —— 黑色 ink 主角，至多一个 Chicago-30 强调色（精确使用一次，例如标 2020 谷底）。**1px 红 rule 替代 10×30 flag + 2px top border**。标题衬线。

#### baseline (no skill) / baseline（无 skill）
- **EN** — What the model produces when *not* loading the skill. Notice the visual signature is *deformed*: 3 px red bar instead of 10×30 flag, grey kicker instead of red, cream `#FFFEF6` background, red-highlighted word in title. Same dataset, same topic, but visibly off-brand.
- **中文** —— **不加载 skill 时**模型自己产出的版本。视觉签名**变形**了：3px 红条替代 10×30 flag、灰色 kicker、奶油 `#FFFEF6` 背景、标题里有红色高亮词。同一份数据、同一话题，但**明显不像**品牌。

## 4. How to regenerate / 如何重新生成

**EN** — To reproduce:

1. Load the skill in your agent runtime.
2. Send the prompt: *"Make an Economist-style information graphic in HTML for China GDP growth 2010-2024, mood = [mood]."*
3. Save the output, run the Step 8 self-check.

For PPTX, run `python3 scripts/build_ppt.py` directly (requires `python-pptx`; optional `--output` path).

**中文** —— 要复现：

1. 在 agent 运行环境加载本 skill
2. 发送 prompt："做一个经济学人风格 HTML 信息图，中国 GDP 2010-2024 增长，mood = [mood]"
3. 保存输出，跑 Step 8 自检清单

PPTX 直接跑 `python3 scripts/build_ppt.py`（需要 `python-pptx`；可用 `--output` 指定输出路径）。
